# План: карточка объекта (frontend/app/info.tsx)

Ограничение: только нативные элементы (`@expo/ui/swift-ui`, `expo-router` toolbar, SF Symbols).

## 1. Строка быстрых действий — В РАБОТЕ
Маршрут пешком (Apple Maps, `dirflg=w`), избранное (локально, AsyncStorage), аудиогид.
Плавающая кнопка аудиогида заменяется кнопкой в строке.

## 2. Галерея фото
Горизонтальный свайп (`TabView`) вместо одного фото. Нужно несколько фото на объект (backend).

## 3. Блок «Рядом»
3–5 ближайших объектов, переход на их карточки. Данные: `getNearbyMonuments`.

## 4. Расстояние и «открыто сейчас»
«1,2 км, 15 мин пешком» (нужен `expo-location`) и статус по `opening_hours` (нужен разбор строки).

## Дальше (идеи)
- «Был здесь» (Toggle), геймификация вместе с квизом

- Стоимость выделенно, время посещения, доступность (поля в backend)
- Блок «Интересный факт», «В каких маршрутах»
- Герой edge-to-edge под прозрачным навбаром, чипы-теги из `tags_json`
